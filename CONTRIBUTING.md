# Contributing to Crispy

Thanks for your interest in contributing!

## Getting started

1. Fork and clone the repository
2. Install dependencies with `bun install`
3. Start the app with `bun start`

## Pull requests

- Open a draft PR early if you want feedback
- Keep changes focused and well described
- Ensure the app still runs on iOS, Android, and web when relevant

## Questions

Open an issue if anything is unclear. Happy shipping!
